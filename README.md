# Khaja-Adda

Nepali Gen-Z themed food delivery landing page with direct Call and SMS buttons.

## Run locally

Open `/home/runner/work/Khaja-Adda/Khaja-Adda/index.html` directly in a browser,
or run:

```bash
cd /home/runner/work/Khaja-Adda/Khaja-Adda
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.
