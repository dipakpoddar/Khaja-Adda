# Khaja-Adda

Nepali Gen-Z themed food delivery landing site for **Khaja Adda**.

## Features
- Nepal-first visual identity (colors, copy, vibe, and local food references)
- Gen-Z flavored section names like **Vibe Zone**, **Khaja Bazar**, and **Sathi Boleko**
- One-tap direct action buttons:
  - `tel:` call button that opens the phone dialer
  - `sms:` message button that opens the SMS app with prefilled text
- Animated reveal effects, floating cards, and interactive food-category filtering
